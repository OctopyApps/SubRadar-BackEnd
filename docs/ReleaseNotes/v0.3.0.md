# SubRadar Backend v0.3.0

Первый релиз в новом самостоятельном репозитории — код перенесён из
`OctopyApps/SubRadar` (директория `backend/`) с сохранением истории
коммитов. Помимо самого переезда, релиз включает большой объём security
и correctness работы, поддержку веб-клиента и Web Push.

## Безопасность

- Убран закоммиченный секрет из `config.yaml` — старый ключ считается
  скомпрометированным, конфиг больше не хранится в git.
- Сервер отказывается стартовать с дефолтным/слишком коротким
  `jwt_secret`/`server_secret` (< 32 символов) вместо тихого запуска с
  предсказуемым ключом.
- Таймауты на HTTP-сервере (`ReadTimeout`/`WriteTimeout`/`IdleTimeout`) —
  защита от зависших соединений.
- Graceful shutdown по `SIGTERM`/`SIGINT` — сервер дожидается текущих
  запросов и корректно закрывает БД.
- Constant-time сравнение `server_secret` при self-hosted входе.
- Rate limit (5 попыток/мин с IP) на все публичные `/auth/*` эндпоинты.

## Корректность

- Определение конфликта UNIQUE теперь идёт по коду ошибки SQLite-драйвера,
  а не по подстроке в тексте ошибки.
- `Update`/`Delete` для подписок, тегов, категорий и валют теперь честно
  возвращают `404`, если запись не найдена или принадлежит другому
  пользователю (раньше — `500` или вводящий в заблуждение `204`).

## Веб-клиент

- CORS: self-hosted режим по умолчанию разрешает любой origin, если не
  задано явно (не влияет на мобильные клиенты).
- Токен доступен через httpOnly cookie в дополнение к телу ответа —
  веб-клиент может не использовать `localStorage`.

## Web Push

Напоминания о скором списании подписки для веб-клиента (PWA) — у браузера
нет аналога локальных уведомлений iOS:

- `GET /push/vapid-public-key`, `POST/DELETE /push/subscribe`.
- Дефолтный и переопределяемый по устройству список "за сколько дней
  напомнить" (`push_lead_times`).
- Ежедневная фоновая джоба с дедупликацией и очисткой мёртвых подписок.
- Полностью опционален — не активируется без VAPID-ключей в конфиге.

## Тесты

Backend был покрыт тестами практически с нуля: интеграционные тесты для
`/subscriptions`, `/tags`, `/categories`, `/currencies`, `/push/*`, юнит-тесты
для конфигурации и фоновой джобы. `tests/RUN_ALL.sh` — единая точка запуска,
используется и локально, и в CI.
